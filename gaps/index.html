Website Scan

How far the surface is from a modern AI engineering site

Current strength

The site has strong proof content: Projects, Reports, Learn, Questions, public catalogs, benchmark numbers, and limitations.

Main question

The central question is how to make the proof more explorable. A modern technical portfolio should let a visitor interact with a demo, inspect a system map, and see visual proof in the first minute.

Distance

Medium. The foundation is credible and content-rich, but it needs an interactive proof demo, 3D system map, richer charts, and a clearer preview path before it feels like a 2026 AI engineering surface.

Interface questions now open

  • Create an interactive proof tour that walks through AML Engine, Agent Chess, Heartbeat Lab, Reports, and Questions.
  • Create a 3D or spatial system map where proof lanes are nodes and evidence links are edges.
  • Add chart PNG and PDF exports from the report catalog.
  • Add a local preview guard so file preview does not look broken when root assets are not loaded.
  • Keep 3D functional: use it to explain system structure, not just as decoration.
  • Add a stack radar that teaches current AI engineering layers and maps each layer to a proof surface.
