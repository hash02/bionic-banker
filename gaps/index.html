Search
Search

When is vector search better than keyword search?

Why people ask: Search gets harder when a visitor asks in different words than the article or dataset used.

Plain answer: Keyword search looks for exact words. Vector search looks for meaning, so it can find a relevant passage even when the wording is different.

Existing example: The Modern AI Stack Radar defines embeddings and connects them to RAG, observability, and proof pages.

Useful for reader: Useful if you are comparing a normal search box with an AI search or knowledge assistant.

System Design
System Design

If you have two AI components, how do you connect them without creating a messy system?

Why people ask: Modern AI work often has separate parts: retrieval, tools, memory, evaluation, user interface, and approval gates.

Plain answer: Give each component a clear contract. One part should know what it receives, what it returns, what it is allowed to do, and what gets logged.

Existing example: Proof Tour shows connected lanes for AML, agent coordination, heartbeat rows, governance, reports, and learning concepts.

Useful for reader: Useful if you are trying to understand how small AI pieces become one usable workflow.

Evaluation
Evaluation

How do you know an AI workflow improved instead of just changed?

Why people ask: A model can feel better while becoming less reliable on edge cases.

Plain answer: Use eval rows. Pick sample questions, expected behavior, pass or fail criteria, and notes. Then compare changes against the same set.

Existing example: Reports shows benchmark-style values, limitations, and method notes so numbers are not floating claims.

Useful for reader: Useful if you are reviewing AI output quality or deciding whether a change is actually better.

Governance
Governance

What should an AI agent be allowed to do by itself?

Why people ask: Finance, healthcare, and compliance workflows need role boundaries, approval gates, and reviewable actions.

Plain answer: Start with roles. Some actions can be read-only, some require review, and some should stay human-only. The log is part of the product.

Existing example: Learn defines RBAC, audit logs, tool calling, and MCP as one governance pattern.

Useful for reader: Useful if you are thinking about AI agents in regulated or high-trust workflows.
