Bionic Banker Context Engine

Show the source. Show the question. Show what the system cannot decide.

The context engine is the layer between raw source access and action. It keeps Bionic Banker useful without turning signals into advice, wallet movement into accusation, or agent output into unchecked authority.

Operating rule

Source trail to human next step.

A context engine is not just search. Search can find a plausible line. A context engine keeps the source, missing context, disagreement, privacy limit, and human next question attached to the line.

source trail context question missing context clear limit human next step
Five checks

Every useful record should survive this loop.

01 / Source

Start with one public source trail

A price row, wallet label, explorer page, article, system record, or human correction enters the map with its source still visible.

02 / Context

Ask what the source can and cannot support

The context check looks for date, source quality, conflict, related records, stale notes, and the narrow question the source can answer.

03 / Missing context

Name the gap before interpretation

A movement, model answer, or risk note is incomplete until the page says what is unknown, what would change the reading, and what must stay private.

04 / Limit

Keep the action boundary beside the record

The system can organize a record. It cannot approve KYC, file a report, move funds, control a wallet, or tell a reader what to trade.

05 / Human next step

Compress the work into one useful question

The output should be small enough to use: a review question, source note, report update, article fix, or system check that a person can inspect.

Blocked actions

What this layer cannot do.

  • No trading call or copy-trade instruction.
  • No KYC approval, SAR filing, enforcement, or compliance verdict.
  • No wallet, transfer, exchange, or fund-control power.
  • No hidden private prompt, customer data, employer data, or secret source.
  • No claim that one row proves intent, ownership, or future price movement.
