# QA Reports

Generated QA artifacts are written here by `_astro-source/scripts/qa-mobile.mjs`.

- Latest local report: `qa-reports/latest/report.md`
- Latest machine-readable report: `qa-reports/latest/report.json`
- Latest screenshots: `qa-reports/latest/screenshots/`

`latest/` is ignored by git. Commit durable summaries under `docs/` or `site-agent/` only when a report becomes part of a longer-lived incident record.
