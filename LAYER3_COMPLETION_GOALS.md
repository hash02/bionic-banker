# Layer 3 Completion Goals

Bionic Banker Layer 3 is the public field map for AI, finance, agents, signals, apps, and trust systems.

## Goal 1: correct domain reality

- Target domain from Hash: `bionicbanker.tech.com`.
- Current DNS check: `bionicbanker.tech.com` does not resolve from this machine.
- Completion rule: do not claim live-domain success until DNS resolves and the browser shows the pushed Layer 3 homepage.

## Goal 2: Signals becomes a bounded signal board

The Signals page should feel alive, but careful.

It must show:

- market rows as research context
- saved heartbeat rows as evidence
- confidence as a model read, not a trade instruction
- clear limits: not investment advice, not trading performance, not a recommendation

## Goal 3: Apps becomes the strongest reviewer entry route

The Apps page should answer a cold reviewer in one pass:

- what can I enter
- what judgment does it show
- what evidence supports it
- what boundary keeps it honest
- which three apps should I inspect first

## Goal 4: AI Intelligence becomes the Agent Her plus Hash watch surface

The AI Intelligence page should show the collaboration loop:

- Hash brings outside-world signals and finance context
- Agent Her turns them into questions, tests, pages, and safer systems
- useful patterns become apps, field notes, or checkers
- hype stays out until it can produce evidence

## Goal 5: gates stay strict

Before shipping:

- `npm run qa:proof`
- `npm test`
- `npm run qa:mobile`
- `git diff --check`
- browser check homepage, Apps, Signals, AI Intelligence
- verify raw GitHub after push
- verify live domain only if DNS resolves
