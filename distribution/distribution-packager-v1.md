# Bionic Distribution Packager v1

Status: locked operating workflow
Date: 2026-06-18

## Purpose

Turn one Bionic Banker article or content idea into platform-native distribution packages without spammy behavior.

## Input

```text
article_slug
topic
core_claim
source_url
visual_path
```

## Output folder

```text
distribution/packs/<slug>/
  linkedin.md
  x-thread.md
  reddit-answer.md
  devto-hashnode-angle.md
  first-comment.md
  metrics-row.yaml
  pre-post-checklist.md
```

## Locked package logic

### LinkedIn

```text
recognizable mistake
→ sharp control model
→ practical checklist / image
→ practitioner question
→ article link in first comment
```

### X

```text
one sharp thesis
or 5–7 post thread
one idea per post
no LinkedIn paragraphs
```

### Reddit

```text
helpful answer first
no link unless useful and allowed
subreddit rules before posting
```

### Dev.to / Hashnode

```text
tutorial / diagram / implementation note
public-safe technical framing
```

### Website

```text
source of truth
article + visual + sources + boundary language
```

## Non-negotiables

- No fake engagement.
- No engagement pods.
- No mass DMs.
- No link dumping.
- No copying competitor identity.
- No legal/investment/tax/compliance determinations.
- No private Wukong/Hermes/internal machinery.
- No public posting unless approved or separately authorized.

## Pre-post checklist

```text
[ ] Hook is a recognizable mistake.
[ ] Visual is readable on mobile.
[ ] Caption has one clear control model.
[ ] Link is in first comment, not main body.
[ ] Practitioner question exists.
[ ] Hashtags are sharp and limited.
[ ] Platform rules/norms checked.
[ ] Metrics ledger row prepared.
[ ] Stop conditions reviewed.
```
