Prompt Injection

AI can be hacked through instructions.

The risk is not a spooky prompt. It is untrusted text crossing into trusted instruction, tool, or approval space.

Trusted

System rules

Policy, role, tool limits, approvals.

Untrusted

Hidden instruction

Email, PDF, web page, retrieved note, tool result.

What the AI sees

The model needs the system to separate evidence from commands.
