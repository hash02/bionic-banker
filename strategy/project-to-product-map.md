# Project-to-Product Map: Bionic Proof Assets

Date: 2026-06-15

## Goal

Turn existing projects into portfolio/product surfaces that show practical capability without sounding like generic resume projects.

Bionic Banker should present them as **control-layer demos**, not random apps.

## Product surfaces

### 1. AML Engine

Positioning:

> A financial-crime triage engine that turns public signals and wallet/activity records into review queues, evidence trails, and human-readable risk notes.

Public surface:

- demo page
- architecture diagram
- sample sanitized case
- risk scoring explanation
- limitations boundary

Product form:

- lightweight web app
- CSV/API input
- dashboard output
- PDF risk memo export

Do not claim:

- regulatory certification
- legal compliance determination
- law-enforcement-grade attribution
- guaranteed AML detection

### 2. Agent Wallet Control Layer

Positioning:

> A safe testnet wallet-control lab showing how AI agents should be bounded before they can prepare or request transactions.

Public surface:

- control map
- testnet demo
- policy YAML
- receipt database
- human approval screen

Product form:

- open-source demo / local app
- downloadable policy kit
- consulting proof-of-work

### 3. AI Finance Operator Tutorials

Positioning:

> Practical tutorials for using AI around finance without losing source discipline or human approval.

Public surface:

- tutorials
- checklists
- carousels
- source maps

Product form:

- downloadable review kits
- templates
- paid PDF packs later

### 4. Competitor/Trend Intelligence Desk

Positioning:

> A local-first intelligence desk that watches AI finance, crypto compliance, stablecoins, and AI governance signals, then creates source-backed briefs.

Public surface:

- weekly public memo
- “what changed” pages
- source map visuals

Product form:

- subscription/report later
- consulting lead magnet

## Website framing

Avoid:

```text
Here are my projects.
```

Use:

```text
Control Layer Demos
```

Possible site section:

```text
Labs
- Agent Wallet Control Layer
- AML Review Engine
- AI Finance Operator Tutorials
- Bionic Intelligence Desk
```

Each lab page should include:

1. problem
2. control gap
3. architecture
4. demo artifact
5. limitations
6. what this proves
7. next version
