Event Router (Level 4 — Reactive)

on: push (*.html)
new_article
New HTML pushed to bionic-banker → auto-runs 8-point content audit (meta, OG, links, JSON-LD)
→ content-audit-auto.py → memory/
on: health check fail
health_fail
Health check detects issues → routes alert to OUTBOX + creates task in INBOX for Claude Code
→ event-router.py → OUTBOX.md
on: self-heal success
push_success
Health check auto-fixes known issues (article count, stale timestamps) → logs the self-heal
→ event-router.py → SESSION_LOG.md
on: task > 7 days idle
stale_detected
Staleness detector finds tasks idle >7d (STALE) or >14d (DEAD) → writes recommendation
→ event-router.py → OUTBOX.md
