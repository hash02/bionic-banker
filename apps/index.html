Quality rule Every card has to be clear.

Each card should answer five plain questions: what it is, what it does, why it matters, what you can check, and what it cannot do. Anything weaker stays in private notes until it is clearer.

The clearest path is Wallet Risk, AML Status, Fraud Alert Triage, Agent Workflow Case Review, then Agent Chess. Read one page at a time: a row is checked, a note explains the risk, the source stays visible, and a person keeps final control.

How to read it

Recommended path

Start with Wallet Risk Assessment for risk judgment, AML Status for clear audit limits, Fraud Alert Triage for case assembly, Agent Workflow Case Review for review discipline, then Agent Chess for human-reviewed agent operations. That sequence shows the core pattern: assess a financial object, keep the source visible, review the AI move, and keep outside actions behind human review.

Quality rule: if a line cannot point to a source, a number, a screenshot, a test, or a clear limit, it does not belong here yet.
