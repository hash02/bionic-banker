AML Status

The status is only useful when a reader can see what was checked and what the system cannot do.

This page shows an AML status record without turning it into a compliance claim. It explains the rule, the source trail, the planner limit, and the parts that stay local.

What this showsAn AML status can be checked and explained without giving the system approval, filing, wallet, trade, or deploy power.

Status rule

A status row has to show its work.

The AML status contract only trusts a row when the source, counts, rule coverage, and freshness checks are present.

30-infrastructure/aml-engine/AML_LAYER1_STATUS_CONTRACT.md
What it cannot do

The planner can prepare a note. It cannot act.

Every compliance gate keeps action approval set to false. In plain English: this can prepare a proposal, but it cannot approve, file, trade, deploy, or execute.

console-api/wukong-side/mc_aml_planning_endpoints.py
Source trail

The record shape comes before the public claim.

The local contract defines JSON and Markdown records, latest aliases, and SHA-256 sidecars so a later reader can inspect what supported the status.

70-ops-logs/aml-evidence/<timestamp>-aml-evidence.{json,md} plus aml-evidence-latest aliases and .sha256 sidecar
What is visible

Public-safe claims

  • AML status can only be treated as evidence-backed when stub is false, counts exist, source metadata exists, rules are loaded, and freshness checks pass.
  • Planning/advisor gate outputs carry proposal_clean and may_execute fields, with may_execute remaining false on every branch.
  • Canonical local evidence artifacts are defined as JSON, Markdown, latest aliases, and SHA-256 sidecars under the vault operations log pattern.
  • Mission Control UI surfaces evidence status, blockers, source freshness, evidence artifact status, artifact path, evidence hash, and artifact age.
  • The public page is a evidence surface, not an operational compliance product.
What stays bounded

Not an execution system

  • Outside action allowed: false
  • KYC approval allowed: false
  • Wallet or trade movement allowed: false
  • Report filing allowed: false
  • Deployment allowed: false
