Agent Governance Flow

Move → Review → Gate → Artifact → Log → Human Approval

1. Move

An agent proposes a bounded action: inspect, draft, classify, test, or summarize.

bounded work

2. Review

A second pass checks evidence, wording, risk, and whether the next step is allowed.

fresh eyes

3. Gate

The approval limit separates local support work from external action.

external actions blocked

4. Artifact

The system leaves an inspectable output: evidence record, visual, report, or summary.

reviewable output

5. Log

The audit trail records what changed, what was checked, and what remains gated.

decision history

Human Approval Boundary

Agents may inspect, draft, classify, summarize, test, package, and report.

Agents may not apply, post, trade, move funds, file compliance actions, or message externally without explicit approval.

Career signal: operational governance — visible evidence, blocked authority, reviewer control, and human review required.
