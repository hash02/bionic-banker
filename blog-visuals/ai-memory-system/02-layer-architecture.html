The Five-Layer Memory Architecture

Critical (read every session)
Novel (immune system)
Supporting
▲ HIGHEST PRIORITY LOWEST PRIORITY ▼
L1
Boot Memory
boot_context.md
Working memory. 10-second orientation. What matters right now, what's broken, what's live. Read before anything else.
Human equivalentGlancing at your desk before starting work
L2
Episodes
session_log.md
Episodic memory. What happened, in order. Decisions made, context of WHY. RAG can't replace temporal sequence.
Human equivalentYour journal — not what's true, but what occurred
L3
Immune System
immune_log.md → rules
Antibody memory. Mistakes logged → lessons extracted → rules hardcoded → startup inherits them. System gets harder to break.
Human equivalentYour body remembering a virus and building defenses
L4
Identity
identity.md
Procedural + declarative. Rules, personality, project state, voice. What makes a new session feel like the same agent.
Human equivalentYour values, habits, expertise — what makes you YOU
L5
Knowledge Base
knowledge_base.md
Semantic long-term memory. Patterns, mental models, connections. The system works without it — it's the least critical layer.
Human equivalentYour library, bookmarks, notes
The counterintuitive insight: everyone builds Layer 5 first (vector databases, embeddings). The top three layers matter more for actual continuity.
