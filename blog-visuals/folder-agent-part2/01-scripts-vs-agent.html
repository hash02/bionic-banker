What Makes It An Agent
💓
Heartbeat Daemon
A persistent process that wakes up every 6 hours. Checks folder state. Acts if needed. Sleeps. Repeats forever — even when laptop is closed.
heartbeat.py — 50 lines
🧠
Self-Calling Brain
Uses a private model boundary on a schedule. The public page shows the control pattern, not provider calls, prompts, or raw action JSON.
Decision layer — private boundary
📱
Telegram Push
Sends real-time notifications to my phone. I can approve proposals, trigger audits, or check status from anywhere. Two-way communication.
comm.py — multi-channel
🛡️
Hard Safety Whitelist
7 allowed actions, hard-coded. Anything else gets blocked and logged. The brain can think about anything but only DO 7 things. Default: noop.
SAFE_ACTIONS — 7 actions
