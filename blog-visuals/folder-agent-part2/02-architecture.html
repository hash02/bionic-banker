Agent Architecture — One Cycle

Each heartbeat runs this flow. ~2 seconds per cycle. Repeats every 6 hours.
1
state.py — Read Folder
Scans TASKS.md, INBOX.md, OUTBOX.md, proposals.md, outcomes.json, latest audit & health reports. Compresses to ~2000 tokens.
state = read_folder_state(workspace)
2
Decision layer — private model call
Receives a compact state summary, applies a private decision rule, and returns the next allowed action without exposing prompts or provider routing.
Private decision record → allowed next action
3
heartbeat.py — Execute Actions
Iterates through actions. Each one checked against SAFE_ACTIONS whitelist. Blocked actions get logged. Safe actions get executed.
for action in decisions["actions"]: execute_action(action)
4
heartbeat.py — Log Everything
Full cycle logged to agent/logs/ as JSON. State snapshot, brain decisions, action results, timing. Every cycle is auditable.
cycle_log → agent/logs/cycle_20260308_140000.json
5
comm.py — Notify HASH
If actions were taken, sends summary via Telegram → email → file (fallback chain). Agent is never silent.
notify("🤖 2 actions taken. Check logs.")
↻ sleep(21600) → repeat
Default: every 6 hours. Configurable. Max 10 calls/day (cost safety).
