How this works

  • Cadence: every ~10 minutes (loosely aligned with Bitcoin block cadence).
  • Data: 30 most-recent 5-minute BTC candles from Binance public API. No API key needed.
  • Predictor: deterministic — last-3 returns + RSI(14) + volume z-score, weighted vote.
  • Narration: gemma2:2b via Ollama running locally on the agent host. Best-effort, never blocks the prediction.
  • Resilience: three modes (HEALTHY, DEGRADED, MINIMAL). Local LLM keeps the agent reasoning even with no internet.
  • No money: this is a public track-record only. No live trading on these signals.
